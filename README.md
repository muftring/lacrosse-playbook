# lacrosse-playbook
App to work-out Lacrosse Plays

# Conversation with Claude

## First Request
> I need an electron app to help me strategize girls lacross plays. The app should present the full playing field with markings for girls lacrosse. It should allow me to drag and drop markers for the players on two teams. The markers should be circles and the fill-color should be selectable per team. I should be able to name each team, and possibly name each marker with a player's name (maybe the names is visible on hover?). I would like to be able to draw wide 2D arrows on the field to show movement of the play. I would like to be able to add text boxes to the field to write/capture notes. I would like to be able to create plays, name the plays, and save time sequenced snapshots of the field with markers in the plays. I would like to be able to export a play to a PDF with each page being one of the captured snapshots.
